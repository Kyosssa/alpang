## 3. 검색 연동
**잘 된 점:** `#alpangSearch`·`#sbResults`·`#sbGo` ID 유지, `.sb-wrap{position:relative}` 래퍼, 시안의 `.search button` 충돌을 피해 `.searchbar`로 개명, `.sb-more` 독자 스타일, `text-align:left`, z-index 60(상단 메뉴 20 위), `search.js`·`data-index`를 현행 경로로 이관하도록 주석 표시.

**고칠 점**
1. **드롭다운이 열리지 않습니다.** `search.js`는 결과 상자에 `open` 클래스를 붙여 보이게 하는데 시안은 `.sb-results{display:none}`만 있고 `.sb-results.open{display:block}`이 없습니다. 이 규칙과 결과 항목 스타일(`.sb-item`·`.sb-badge`(+map/item/npc/quest)·`.sb-icon`·`.sb-nm`·`.sb-en`·`.sb-unv`·`.sb-none`)이 시안에 **모두 빠져 있습니다**. 현행 홈 CSS를 시안 변수명(`--txt`·`--acc`·`--dim` 등)으로 옮긴 파일을 `sb-css-for-main2.css`로 드립니다(`.sb-more` 규칙 아래에 붙이면 됩니다).
2. **수치 주입 스크립트: 삭제하세요.**
   - `fetch('/assets/alpang-search-20261028-12.json')`로 **홈을 열 때마다 5.96MB(전송 약 589KB)** 를 내려받아 숫자 3개를 채웁니다.
   - 게다가 작동하지 않습니다. 인덱스는 `{records:[…]}` 구조인데 코드는 `idx.items || idx`를 배열로 취급해 `forEach`에서 TypeError가 나고 `.catch`가 삼킵니다. 즉 지금은 폴백 값(188/419)이 그대로 남습니다.
   - 설령 작동해도 `-12` 인덱스는 몬스터 175건이라 188을 175로 덮어씁니다.
   - 숫자는 **빌드 때 주입**하세요(인덱스 -13 생성 시점의 집계로). 이 홈은 검색 인덱스를 쓰려면 사용자가 검색창에 포커스한 뒤에만 로드돼야 합니다.
3. 검색창 안내 문구가 "몬스터, 아이템, 맵 검색"인데 칩은 NPC·퀘스트까지 있고 인덱스도 NPC·퀘스트·직업·스킬을 포함합니다. 문구를 통일하세요.
4. `<form>`이 없어 Enter 키는 선택 항목이 있을 때만 이동합니다(현행과 동일, 확인 사항).
