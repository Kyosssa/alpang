## 4. 해결되지 않은 것 (확인 필요)
1. **스킬 ID의 원천은 피클이 KMS 1.2.160 클라이언트(2.8GB)를 직접 파싱한 결과**입니다. 저는 이 파싱을 재현하지 못했고 위 구조 정합만 검증했습니다. 장 하나의 ID가 틀려도 정합에서 잡히지 않을 수 있습니다.
2. **캐논 파이렛 스피릿 — 해소(2026-11-20).** 최종 ID는 **5321010**입니다. 피클의 1.2.160 클라이언트 파싱 보고서(`20261119-2105`, §5)에서 532.img의 전 스킬 12개·String.wz에 5320013이 없고 5321010이 M30 단일 스킬(패시브 반격 + 액티브)임이 확인됩니다. 따라서 "5320013 채택·5321010은 액티브 버프형 사본"이라는 피클 원본의 `id_note`와 `확인_필요_동명ID` 사유 문장은 정정 전 서술입니다. 02 JSON의 해당 항목에 통일된 노트를 넣었고, **피클 원본 파일(`incoming/pickle/justice_t2_skill_id_20261119.json`)의 두 문장은 피클가 직접 교체**해야 합니다(원본은 제가 수정하지 않았습니다).
3. 사용 무기의 '보조 무기'(마법화살·화약통)도 현행 기준이며 2012 시점은 미확인입니다.
