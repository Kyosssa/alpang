# 알팡지지 2.0 이미지·성능(LCP) 최적화 기준 (2026-11-20, 기술이사)

범위: 2.0 메인(헤네시스 히어로 배경 · 핵심 도구/가이드 카드의 인게임 스프라이트 · 미니맵 썸네일). **3차 시안 파일은 저장소에 올라오지 않아 2차 시안(`packages/main2-preview-20261119/index.html`)과 라이브 홈 에셋 실측을 근거로 했습니다.** 시안의 이미지(`hero-henesys.jpg`·`mob-*.png`·`item-*.png`·`minimap-ludi.png`)는 에셋이 미업로드(바이너리)라 용량을 알 수 없습니다.

## 0. 현행 기준선 (라이브 홈 실측)
- 홈이 쓰는 이미지 26종, 합계 **약 1.2MB**. 히어로 슬라이드 webp 57~101KB, 카드 webp 20~60KB(대부분 `loading=lazy`).
- **불균형:** 로고 `logo.png` **142,785B**(화면 높이 30px), 아이콘 PNG 3종 **54~102KB**(검색·확성기·단풍잎), 두 항목이 슬라이드 한 장보다 큽니다. 2.0에서 같은 파일을 쓰면 LCP 직전 구간을 불필요하게 무겁게 합니다.
- 첫 슬라이드만 `fetchpriority="high"`, 나머지 `lazy`+`decoding=async`는 이미 올바릅니다(이 방식 유지).
- 글꼴은 jsDelivr의 `pretendard.min.css`(정적 전체 가중치) 한 개를 렌더 차단 CSS로 불러옵니다 — 텍스트 LCP의 숨은 변수입니다(§4).
- 모바일 LCP를 이번에 숫자로 재지는 못했습니다(내장 브라우저에서 LCP 항목이 수집되지 않았고, 캐시된 빠른 회선이라 대표성이 없음). 아래 §5 절차로 실측한 뒤 기준을 확정하세요.

## 1. 헤네시스 히어로 배경 — 렌더 규격
| 항목 | 규격 |
|---|---|
| 방식 | CSS `background`(시안)에서 **`<img>`+`fetchpriority="high"`로 교체**하거나 `<link rel="preload" as="image" imagesrcset=… imagesizes=…>`. CSS 배경은 파서가 늦게 발견해 LCP가 밀립니다 |
| 포맷 | WebP (필요하면 AVIF를 `<picture>` 1순위로, 폴백 WebP) |
| 크기 세트 | **768w · 1280w** 두 장(필요 시 1600w). `srcset`+`sizes="100vw"` |
| 품질 | 시안에서 거의 어두운 그라디언트(.72~.82)가 덮이므로 **q 55~65**, 4:2:0 크로마, 필요 시 약한 가우시안 선처리 |
| **용량 상한** | **768w ≤ 60KB, 1280w ≤ 110KB, 절대 상한 150KB** |
| 지연 로딩 | **금지**(첫 화면 LCP 후보). `decoding="async"`는 허용 |
| 치수 | `width/height` 속성 명시(CLS 방지), 컨테이너에 `aspect-ratio` |
| 자체 호스팅 | 반드시. 외부 이미지 서버 사용 금지(연결 비용·저작권) |
| 대체 | 이미지가 늦어도 단색 배경과 흰 텍스트가 즉시 보이게(텍스트 LCP 허용) |

## 2. 카드 내 인게임 스프라이트(도구 4 + 가이드 6)
- **픽셀 아트는 손실 압축 금지.** 잡음이 생기고 오히려 용량이 큽니다. **무손실 WebP 또는 팔레트 PNG8**을 쓰고 `image-rendering:pixelated`를 유지.
- **원본 해상도로 저장**하고 CSS에서 정수 배율로 확대(예: 원본 32px → 표시 64px). 표시 크기의 2배를 넘는 원본은 줄이세요.
- **용량 상한:** 스프라이트 1개 ≤ **5KB**, 카드 영역 합계 ≤ 50KB. 6개 이상 같은 규격이면 **스프라이트 시트 1장** 또는 인라인 SVG/`data:`(2KB 이하)로 요청 수를 줄입니다.
- **지연 로딩 범위**
  - 핵심 도구 카드 첫 행(모바일 2×2의 위쪽 2개): **즉시 로딩**(첫 화면 하단 경계에 걸립니다).
  - 핵심 도구 나머지·인기 가이드 카드 전부·타임라인: **`loading="lazy"` + `decoding="async"`**.
  - 모든 `<img>`에 `width/height`를 명시(시안에는 없음 — CLS 위험).
- 시안의 `alt`는 의미 있는 값(주황버섯 등)이라 그대로 두되 장식용은 `alt=""`.

## 3. 미니맵 썸네일 (루디브리엄 등)
- 전체 미니맵을 그대로 쓰지 말고 **전용 썸네일 생성**: 표시 크기의 2배(예: 카드 96px 높이 → **400×192 이하**), WebP q 65~75.
- **용량 상한 ≤ 20KB**, 같은 규격 6장까지(한 화면 합계 ≤ 120KB).
- **전부 `loading="lazy"`**(가이드 영역은 첫 화면 아래). 가이드 목록이 길어지면 첫 3장만 즉시, 나머지 lazy.
- 자체 호스팅(`/assets/…`) 필수. `maplestory.io` 직접 참조는 지연이 일정하지 않고 외부 의존입니다.

## 4. LCP를 좌우하는 다른 요소 (이미지 외)
- **로고·아이콘:** `logo.png` 142KB → SVG 또는 WebP ≤ 10KB. 아이콘 PNG 54~102KB → SVG/WebP ≤ 5KB. (가장 즉효인 절약, 약 330KB)
- **글꼴:** `pretendard.min.css`(정적 전체)를 **동적 서브셋판**(`pretendard-dynamic-subset`)으로 바꾸거나 자체 호스팅 서브셋 + `font-display: swap` + `<link rel="preconnect" href="https://cdn.jsdelivr.net">`. 한글 글꼴 용량이 가장 큰 단일 변수입니다.
- **애드센스:** 로더는 `async`라 LCP를 막지 않지만 광고 단위가 생기면 높이를 미리 확보(`min-height`)해 CLS를 막으세요.
- **캐시 헤더:** 현재 정적 자산 헤더가 `max-age=0, must-revalidate`(저장소에 `_headers` 없음). 파일명에 해시를 붙인 자산에 한해 `Cache-Control: public, max-age=31536000, immutable`을 적용(`?v=`은 해시가 아님 — 해시 파일명 전환 뒤에만 immutable).
- **검색 인덱스(5.96MB)**는 첫 포커스 때 로드되므로 LCP에는 무관하지만 첫 입력 지연이 생깁니다 — 별도 문서(검색 검토) 참조.

## 5. 체크리스트 (3차 시안 → 본 작업 → 배포 전)

**규격**
- [ ] 히어로: `<img>`+`fetchpriority=high` 또는 preload, 768w ≤ 60KB / 1280w ≤ 110KB, lazy 아님
- [ ] 히어로 `width/height` 또는 `aspect-ratio` 지정
- [ ] 스프라이트: 무손실 WebP/PNG8, 원본 해상도, ≤ 5KB, `pixelated`
- [ ] 미니맵: 전용 썸네일 ≤ 400×192, ≤ 20KB, 전부 lazy
- [ ] 로고/아이콘 SVG 또는 ≤ 10KB / ≤ 5KB
- [ ] 첫 화면 이미지 합계 ≤ **150KB** (모바일 뷰포트 기준), 초기 이미지 합계 ≤ **300KB**
- [ ] 모든 `<img>`에 `width/height`, 장식 이미지는 `alt=""`
- [ ] lazy 범위: 첫 행 즉시, 그 아래 전부 lazy+async (히어로·LCP 후보는 절대 lazy 금지)
- [ ] 모든 이미지 자체 호스팅(`/assets/…` 절대 경로) — 대만·베트남 홈에서도 깨지지 않게

**성능 목표 (모바일, 4G 스로틀링 시)**
- [ ] LCP ≤ **2.5s**(Good 기준), 내부 목표 ≤ 2.0s
- [ ] CLS ≤ 0.1, INP ≤ 200ms
- [ ] 초기 전송량 ≤ **1MB**(HTML + CSS + JS + 이미지, 광고 제외)
- [ ] 렌더 차단 외부 CSS 0개 또는 서브셋 글꼴만

**검증 절차**
1. PageSpeed Insights(모바일) 또는 Lighthouse 모바일 프리셋을 **3회 측정해 중앙값**을 기록한다. 라이브 현행 홈을 같은 방법으로 먼저 재서 기준선으로 쓴다.
2. LCP 요소가 히어로 이미지인지 헤드라인 텍스트인지 확인한다(`PerformanceObserver`/DevTools). 이미지라면 위 상한이 적용되고, 텍스트라면 글꼴이 변수다.
3. 시안 `assets/` 용량 표(파일 · 포맷 · 가로세로 · 바이트)를 저장소에 올려 상한과 대조한다.
4. 본 작업 후 소스 위생 게이트(`cdn-cgi` 0 · Analytics 0 · beacon 0 · mailto 1)와 `hreflang`·canonical 계승을 확인한다.

## 6. 확인하지 못한 것
- 3차 시안 파일과 시안 이미지의 실제 용량·해상도.
- 실제 모바일 LCP 수치(위 §5 절차로 실측 필요).
- 시안 헤네시스 배경이 `<img>`로 바뀌면 디자인(오버레이·`background-position`)이 달라질 수 있어 디자인 확인이 필요합니다.
