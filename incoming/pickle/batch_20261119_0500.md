## 이번 회차 방법 (다음 회차에 그대로 쓸 것)

1. **게시일 실측 경로 교체**: `/watch` curl이 캡차(302 → google.com/sorry)로 막혀 **InnerTube `POST /youtubei/v1/next`**(clientName WEB / clientVersion 2.20241101.00.00)로 우회. `dateText`·`viewCount`·`subscriberCountText`·AI 배지를 한 번에 파싱, 1,375편 병렬 10으로 약 10분.
2. **프리스크린**: `oar1~3.jpg` 3프레임 → 세로·1900px 이상(500편) → RapidOCR(360x640, 3프레임) 무자막(135편). **OCR 오탐 43편을 별도 풀**로 분리(1~2개 노이즈 토큰만 잡힌 경우) — 확정 2편(`2tuE_lCUVZc`·`rmv-fFpsJrM`)이 이 풀에서 나왔다.
3. **실물 검증**: 후보마다 `/shorts/<ID>` **새로 navigate**. `loadVideoById`는 두 번째 전환부터 stale duration(4.82초)을 반환해 폐기. `ytInitialPlayerResponse`로 원본 해상도·길이·게시일을 먼저 읽고 10초 미만은 모션 없이 탈락. 통과분만 10fps 160x90 gray 차분 + 스파이크 스캔.
4. **8컷 육안**: 250x445 타일 4x2 캔버스를 페이지에 fixed로 얹고 `browser_screenshot(region={x:0,y:0,w:522,h:898})` 1장(뷰포트 1919x992 기준).
5. **하니스 캘리브레이션**: 34차 확정편 `2a1C7J8CSiU` 재측정 **12.23**(34차 12.77, 편차 4%) — 측정 편향 아님 확인.
6. **채널 쇼츠 목록**: `POST /youtubei/v1/browse` + `browseId=<UC…>` + `params=EgZzaG9ydHPyBgUKA5oBAA%3D%3D`로 48편까지 한 번에 확인 가능(단 **게시일은 응답에 없음**).
