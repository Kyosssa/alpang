## 0. 결론 요약

1. **핑크빈 입장 체인 전체를 확정했다.** '과거의 길(140) → 추억의 길1~5(140/145) → 후회의 길1~5(150~155)+얼어붙은 감정+감정을 파는 마제사 → 망각의 길1~5(160) → [망각의 길]여신의 축복 → [망각의 길]결계 → 폐허 너머에' 순이며, 최종 입장 NPC는 **잊혀진 신전관리인**(부서진 회랑 너머 잊혀진 황혼), 선택지는 **'핑크빈 원정대 입장을 신청한다'**다. 1차 미확보 항목이 퀘스트명·시작NPC·레벨·재료·보상·대사까지 채워졌다.
2. **힐라 '선행퀘 없음'은 🔸 보류/미확정이다.** 근거가 **공식 공략 전재 1출처**(manager_ods/100152533557, 2012-03-01)뿐이며 "귀찮은 선행퀘스트가 없다", "원정대 입장을 위한 필요 재료가 없다"는 문구는 그 글의 서술이다. 넥슨 공식 업데이트 공지(Update/215·219·237·251 등)에는 힐라 입장 요건 문구가 없어 **교차검증되지 않았다**. 확인된 것은 입장 절차뿐: **메디사**(아스완 피난처 중앙)의 '승리를 향한 마지막 함성' 수락 → 힐라의 탑 입구에서 모드 선택(노말 120+, 하드 170+), 원정대 1~6인·하루 2회·30분 제한(최저 인원은 1.2.173에서 1인으로 완화).
3. **아스완 퀘스트 13종을 테섭 기준에서 본섭 명세로 승격.** 근거를 전재 블로그에서 **공식 공지를 원문 대조한 결과**로 교체: 본섭 1.2.150(2012-01-12) [Update/215](https://maplestory.nexon.com/News/Update/215)에 13종 제목이 그대로 나열된다(§5-3).
4. **대화창 이미지 OCR 전수 실행.** 관련 50개 글에서 원본 이미지 1,253장을 받아 전부 판독 → **대화창 윈도우 1,383개 / 10자 이상 대화 레코드 795건**. 레코드마다 퀘스트 주제·화자 후보·라인별 원문·conf·이미지 원본 URL·출처 글 URL·작성일이 매핑돼 있다.
5. **판독 품질**: calibrated 파이프라인(§3)에서 신전관리인·기록자·마법제련술사·메디사 대사가 대부분 conf 0.9+로 판독. OCR 텍스트는 **원시 판독값**이며 띄어쓰기·받침 오류를 보정하지 않았다(conf<0.75 라인은 불명확).
6. 부수 확정: 시간의 신전 몬스터 12종 스펙, **잡화상인 '요한나'**(공식 1.2.152 — '이동·포션 NPC'가 아니라 신전관리인 옆 상점 NPC), 잊혀진 신전관리인/기록자/관조자/마법제련술사/키르스턴의 존재·위치, 카오스 핑크빈 입장 조건(170+/3인/14채널/1일 2회). 999→333 킬 카운트는 여전히 **버전 미확정**(공식 1.2.152의 '완료 조건 수정'이 시점·성격상 부합하나 수치 미명시).

## 3. 대화창 OCR — 방법(재현 가능)과 한계

### 3-1. 파이프라인

1. **이미지 수집**: PostView HTML에서 `postfiles.pstatic.net` 원본 URL 추출, `?type=w773`로 1,253장 다운로드(50개 선별 글: 핑크빈 체인 29 + 힐라·아스완 21).
2. **검출**: PP-OCRv4 det(전체) → 텍스트 박스 인접 병합으로 대화창 후보 구성.
3. **판독**: 창 영역 adaptive threshold(31,12) 이진화 → 행 투영 라인 분할 → **한국어 PP-OCRv5 mobile rec**를 라인 단위 직접 구동(자체 CTC 디코딩, dict 11,945자).
4. **화자**: 대화창 인접 이름막대(중간 회색 바+다크 텍스트) 탐지 후 별도 판독. 미검출 시 None.

> **검증 노트**: rapidocr의 rec 경로는 memory-pad 캔버스에서 한국어를 대량 오판한다(같은 모델·같은 입력). det 박스/행 슬라이스를 자체 CTC 디코딩으로 돌리면 동일 모델이 conf 0.9+로 판독한다. 이 교정 없이는 전량 'SrenImm' 수준의 결과가 나온다(2026-11-16 실측).

### 3-2. 한계(보정하지 않은 것)

- OCR 텍스트는 **원시 판독값**. 띄어쓰기 누락/삽입, 받침 혼동, 숫자(경험치) 오류가 남는다.
- 라인별 conf를 그대로 남겼다. **conf<0.75 불명확 / 0.75~0.9 참고 / 0.9+ 신뢰** 구간으로 읽을 것.
- 이름막대가 화면 밖에 잘린 스크린샷은 화자 None — 직전 윈도우 연결로 추정해야 하며 본 문서는 추정을 기록하지 않는다.
- UI(퀘스트 알리미·상점·채팅)를 윈도우로 잡은 오탐 일부 존재. `dialogue_ocr_records.json`의 conf·텍스트로 걸러 읽을 것.
- 20,004px 세로 롱샷 1장(공식 힐라 공략)은 det 메모리 한도로 전수 미처리 → 750px 타일링으로 별도 판독(402 라인, `work/npc_tmp/_fix_m32.json`).
